# 当前论文实现与复现边界

迁移日期：2026-10-22。主算法、特征、冻结模型来自2026-10-19 C-AR改进后版本。迁移只处理路径、模块命名和未使用入口；数值代码、固定参数和候选顺序保留。

## 隔离

运行不需要原 `新实验_*` 目录，也不需要工作区父目录。`source_manifest.json` 记录原源码的相对来源及迁移前后 SHA256。模型另存为仅含 sklearn/numpy 对象的字典，去掉对旧 `RiskSelector` Python 类路径的 pickle 依赖，没有重新拟合参数。原模型和迁移后模型的哈希分别保存在模型元数据中。

开发集144训练会话、48验证会话，各会话3窗×8 chirp。捆绑模型是在固定 `robust_validated` C-AR后、使用原32维特征及负SINR/风险九输出重新训练并通过开发集准入检查的模型。当前模型的后续独立评价包含名义97000～97047及几何扰动98000～98015；这些样例可用于复现诊断，不能再次宣称为未见新留出。

通用 `train` 入口只比较既定两种网络架构，不重跑旧候选开发、旧模型对照、历史准入约束与论文修订工程，因此不能宣称从该入口获得了完整相同的历史模型选择轨迹。论文冻结模型已直接提供，推理与数值重现不需要重训。

## 比较

对每条 chirp 先提取观测特征、预测方法和执行候选；完成后才读取干净目标用于评分。离线最优只用于诊断，不能作为线上输入。新增数据应按整个会话划分，禁止同会话 chirp 泄漏到训练与测试两侧。

重现完整留出可逐 seed 使用 `simulate --windows 0.01 20 39 --chirps 8`；几何队列加 `--geometry`。该仓库不捆绑数GB历史波形，程序重新合成，因此计算时间会高于直接读取旧报告。示例是三条完整复数 ADC，不是新合成的理想信号。

`docs/verification.json` 在发布前写入：移植后的32维特征、三种候选波形、MLP输出与原冻结保存结果的数值比较；接收链生成结果与原ADC的配对比较。运行核对脚本和临时数据保留在仓库外，不发布测试工程。
